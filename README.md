## 🛠️ Local Development

### Prerequisites
- Node.js (v18+ recommended)
- npm / pnpm / yarn

### Installation

1. Clone repository:
   ```bash
   git clone https://github.com/jananimurali0212/portfolio.git
   cd portfolio
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```
